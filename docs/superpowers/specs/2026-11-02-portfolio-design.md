# صفحة «أعمالي» — مواصفات التصميم

## الهدف
صفحة خفيفة ونظيفة يعرض فيها حسين الطويل أعماله (تطبيقات ومواقع) لأصحابه وللناس، بأسلوب متاجر التطبيقات (Galaxy Store / هونور) كصفحة ويب تعمل على الحاسب والآيباد والموبايل.

## التقنية
- HTML + CSS + JS بلا إطار عمل ولا بناء، منشورة على GitHub Pages (`hussein199800.github.io/Website`).
- بيانات المشاريع في `projects.json`؛ إضافة مشروع = إضافة كتلة واحدة.
- خط IBM Plex Sans Arabic (Google Fonts)، عربي RTL.
- وضع فاتح/داكن تلقائي حسب الجهاز + زر 🌙 للتبديل اليدوي (يُحفظ في localStorage).

## الترتيب
1. شريط علوي ثابت: «أعمالي» + بحث 🔍 (يفلتر بالاسم) + زر 🌙.
2. بانر مميز يتبدّل تلقائياً (كل ~5 ثوانٍ): سكينة، سَيْل، موسوعة النقابة.
3. فلاتر: الكل / تطبيقات / مواقع.
4. قسم «التطبيقات» ثم قسم «المواقع»، بطاقات في شبكة: 4 بالسطر (حاسب)، 3 (آيباد)، 2 (موبايل).
5. تذييل: أيقونة ورابط تيليغرام + واتساب.

## البطاقة
أيقونة مدوّرة، الاسم، سطر وصف واحد، تصنيف + إصدار، زر رئيسي («تحميل» للتطبيقات / «فتح» للمواقع)، وزر ⓘ «تفاصيل».
- الضغط على البطاقة أو الزر الرئيسي يفتح الرابط مباشرة في تبويب جديد.
- زر ⓘ يفتح نافذة التفاصيل (وسط الشاشة على الحاسب، ورقة من الأسفل على الموبايل)، تُغلق بـ ✕ أو Esc أو النقر خارجها.
