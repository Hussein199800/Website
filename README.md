# أعمالي

صفحة تعرض أعمال حسين الطويل (تطبيقات ومواقع) بأسلوب متاجر التطبيقات.

- صفحة ثابتة: `index.html` + `style.css` + `app.js`، بلا بناء.
- **لإضافة مشروع:** أضف كتلة في `projects.json` (الحقول: `id`, `type` = `app`/`web`, `name`, `tagline`, `version`, `icon`, `url`, `what`, `features`, `audience`, `goal`, `whatsNew`, `color`، و`note` اختياري)، وضع أيقونته في `assets/icons/`.
- **البانر المميز:** قائمة `featured` في `projects.json`.
- **التشغيل محلياً:** `python3 -m http.server` ثم افتح `http://localhost:8000`.
- **بعد تعديل `style.css` أو `app.js`:** ارفع رقم `?v=` في `index.html` حتى لا يعرض المتصفح نسخة قديمة من الكاش.
- **مزامنة تلقائية:** كل ساعة يقرأ `.github/workflows/sync-releases.yml` آخر إصدار لكل تطبيق له `repo` ويحدّث رقم الإصدار و«شو الجديد» (من نقاط ملاحظات الإصدار) ويفعّل زر التحميل إذا وُجد ملف `apk`. للتشغيل الفوري: تبويب Actions ← «مزامنة إصدارات التطبيقات» ← Run workflow.
- **«شو الجديد» يدوياً:** إذا كانت ملاحظات الإصدار تقنية، اكتب `whatsNew` بنفسك وأضف `"whatsNewFor": "<رقم الإصدار>"` فتبقى حتى ينزل إصدار أحدث.
- **تطبيق قيد التطوير:** `"status": "dev"` يُظهر شارة «قيد التطوير».
- **ملف APK باسم يتغيّر مع الإصدار:** استعمل `"apkPattern"` (تعبير نمطي، مثل `"^tadaffuq-.*-arm64-v8a.*\\.apk$"`) بدل `"apk"`، فتأخذ المزامنة رابط الملف المطابق من آخر إصدار.
- **مشروع بأكثر من قسم:** `"links": [{"label": "...", "url": "..."}]` يُظهر زراً لكل قسم.
- **«آخر تحديث»:** تملؤه المزامنة لكل مشروع له `repo` (تاريخ آخر إصدار للتطبيق، وآخر commit للموقع). `"branch"` لموقع ينشر من فرع غير الافتراضي.
